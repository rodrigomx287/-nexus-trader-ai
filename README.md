# Nexus Trader AI — V1

Starter original de una plataforma de análisis y educación de trading con IA.

## V1 incluida
- Home
- Login / registro (UI; todavía sin backend)
- Dashboard original
- 6 mercados demo
- 4 scanners: Trend, Breakout, Reversal, Liquidity
- Timeframes M5/M15/H1
- Ejemplo BUY/SL/TP1/TP2
- Explicación IA de ejemplo
- Estructura lista para conectar datos reales

## Siguiente conexión

2. Stripe para planes
3. Proveedor de datos de mercado
4. Motor real de scanners
5. Charts con datos reales
